# Security Policy

## Supported versions

The project is pre-release. Security fixes are applied to the latest `main` and, once releases exist, to the most recent release.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately via GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability): go to this repository's **Security** tab and choose **Report a vulnerability**.

Please include the affected version or commit, the impact, and steps to reproduce. For example: a crafted audio file or settings file that crashes the workbench or writes outside the folder you chose.

You can expect an acknowledgement within 7 days. We'll keep you updated until the issue is resolved and credit you in the advisory unless you prefer otherwise.
